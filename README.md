# 腕火屋 — UDEBIYA

架空の本格家系ラーメン店「腕火屋」の静的デモサイトです。2026年9月25日提供の WORK_HANDOFF.md、PC全体案、写真改訂PCヒーロー、SPヒーローを基準に実装しています。

## 起動・生成

Node.js 22以降を使用します。HTML生成には外部依存がありません。公開サイトはアクセス解析用の Google タグだけを外部から読み込みます。

```sh
node build.mjs
node check.mjs
node serve.mjs
```

ローカル表示: http://127.0.0.1:4182/sample_food2/

- `build.mjs`: トップ、メニュー、採用情報、サイトについて（既存の `company/`）のHTML生成元
- `public/assets/site.css`: PC/SPレイアウトと配色
- `public/assets/site.js`: モバイルナビ、案内ダイアログ、メニューのお好み選択
- `public/assets/loader.js`: 筆文字ロゴのトップページローディング、スキップ、読み込み期限
- `public/assets/analytics.js`: 公開URLでのみ動くGA4計測
- `analytics.config.json`: GA4測定ID（公開情報）
- `ANALYTICS.md`: プロパティ設定・イベント定義・集計の読み方
- `public/assets/`: ローカル配信する最適化済み画像
- `ASSETS.md`: 素材の出所・制作プロンプトと処理
- `tests/`: 実ブラウザでの表示・操作検証

HTMLは直接編集せず、`build.mjs` を変更して再生成してください。本文・価格・日付はHTMLで管理し、ページ全体の画像貼り付けは行っていません。ロゴ・「腕」「火」の筆文字は提供画像から分離した透過素材です。

## デザイン・機能

墨黒・生成り・朱赤を中心に、写真の暗部とグラデーションでセクションをつなぎます。PCは左右非対称の構図、700px以下は専用写真と縦組みのヒーローです。本文・ナビ・価格・日付はメイリオ優先、見出しは太い明朝系のシステムフォント、店名と強調文字は筆文字画像です。フォントの実ファイルや外部CDNは使用しません。

ナビ・ページ内リンク・メニュー一覧・予約案内・店舗情報・お知らせ・採用案内を実装。モーダルはTab移動を内部で循環させ、Escapeで閉じ、起点へフォーカスを戻します。メニューのお好み選択は画面内のデモで完結します。動きを抑えるOS設定に対応しています。

トップページを開く・再読み込みするたびに、筆文字ロゴと朱色の円を約1.8秒表示します。下層ページ、ページ内リンクへの直接アクセス、戻る・進む、動きを抑えるOS設定では演出を省略します。SKIPまたはEscapeで解除でき、画像が停止しても約3.2秒で本文の操作を開放します。JavaScriptが無効でも本文を表示します。

FVのラーメンには透過した湯気を重ね、ゆっくり揺らぎながら立ち上らせています。PC/SPそれぞれの丼の位置に合わせ、右下の「湯気 ON/OFF」で停止できます。画面外・非表示タブではアニメーションを停止し、動きを抑えるOS設定では表示しません。

## 表示・操作テスト

テスト開発用依存だけを追加できます。通常ビルドにインストールは不要です。

```sh
npm ci
npx playwright install chromium
npm test
```

既存Chromeを使用する場合は環境変数 `CHROME_PATH` に実行ファイルを指定できます。
375 / 390 / 768 / 1440 / 1920px × 4ページの表示、画像ロード、横はみ出し、JS・HTTPエラー、noindex、ナビ、ダイアログのキーボード操作、お好み選択、サブパスとルート配信を検証します。画面記録とJSON結果は `test-results/` に出力します（Git対象外）。

## 仮設定

実在する住所・電話番号・営業時間・予約先を掲載しません。店舗・価格・2026年10月の開業予定は架空の設定です。問い合わせ・注文・採用応募などの外部送信はありません。全ページの `noindex,nofollow` を維持し、フッターと案内画面にデモサイトと明示しています。
